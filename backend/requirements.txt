# pyproject.toml remains the source of truth for dependencies — this file exists only
# because Azure's Oryx build system looks for requirements.txt and does not understand a
# uv-managed pyproject. Without it, Oryx installs nothing, gunicorn falls back to its
# placeholder app, and every route 404s while the site still looks "up".
#
# Versions are pinned to what the project was verified against. Regenerate after changing
# dependencies in pyproject.toml:
#
#     uv pip compile pyproject.toml -o requirements.txt
#

# psycopg[binary] avoids needing libpq present on the build image.
